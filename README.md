## 🚀 How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/madderofc/madder-ofc-website.git
   ```

2. Open `index.html` in your browser

3. Click on any box to see the content

## 📁 Files

- **index.html** - Main HTML structure
- **style.css** - All styling and animations
- **script.js** - JavaScript functionality

## 🎵 Audio

The website plays background music automatically on first user interaction. Music volume is set to 30%.

## 🎨 Customization

You can easily customize:
- Anime background images (edit `animeBackgrounds` array in script.js)
- Colors (modify color values in style.css - currently using #ff00ff and #00ffff)
- Channel links (update URLs in script.js)

## 📱 Responsive

The website is fully responsive and works great on:
- Desktop
- Tablets
- Mobile phones
